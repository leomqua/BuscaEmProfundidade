# Busca em Profundidade

Implementação em Python de uma busca em profundidade (DFS) usando lista de
adjacência e pilha.

O projeto contém:

- `GrafoListaAdjacencia.busca_em_profundidade(inicio)`: percorre o grafo e
  retorna os vértices na ordem em que foram visitados.
- `GrafoListaAdjacencia.possui_ciclo(inicio=None)`: detecta ciclos em grafos
  não direcionados usando o vértice pai de cada item da pilha.
- `grafo.py`: implementação completa e demonstração com o grafo da atividade.

## Executar

```powershell
python grafo.py
```
